# Twitch 定時發話

Twitch 聊天室定時發話工具 ── 使用自己的帳號，定時自動發送多則訊息到聊天室。

## 功能

- 多則訊息管理（新增、編輯、刪除、啟用/停用）
- 兩種排程模式：固定間隔 / 隨機範圍
- Web Worker 計時器，不受瀏覽器背景分頁節流影響
- 主線程節流偵測，即時顯示頁面狀態
- 瀏覽器設定建議，引導使用者最佳化

## 使用方式

1. 開啟 `index.html`
2. 選擇頻道
3. 使用 Twitch 帳號登入
4. 新增要定時發送的訊息，設定排程
5. 點擊「開始全部」

## 瀏覽器建議設定

- `chrome://flags/#intensive-wake-up-throttling` → Disabled
- 將分頁釘選（右鍵分頁 → 釘選）
- 保持分頁為可見狀態
